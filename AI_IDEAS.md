  - Использует fuzzy matching (similarity ≥ 70%)
- ✅ **Показ ID при добавлении** - после добавления события показывает его ID
- ✅ **Общее количество событий** - при просмотре списка показывает "всього X"
- ✅ **Категоризация событий** (2026-04-14)

  - Эмодзи категории отображается в списках и результатах поиска
- ✅ **Локальный ID** - у каждого пользователя своя нумерация (#1, #2, #3...)
- ✅ **Месячный дайджест** (2026-04-14)
  - Кнопка "📊 Дайджест місяця" показывает сводку
  - Группировка событий по категориям
  - Список всех событий за месяц

  - Поддержка: одиночные ID, через запятую, диапазоны

## Планируемые функции 🔜

### 1. Умные напоминания
**Описание**: Персонализированные сообщения с учётом типа события
**Пример**: 
- День рождения: "🎂 Завтра день рождения! Не забудь поздравить!"
- Дедлайн: "⚠️ Осталось 2 дня до..."

### 2. Предиктивные напоминания
**Описание**: Предсказывает важные даты на основе прошлых событий
**Логика**: "В прошлом году в это время было событие X"

### 3. Экспорт в календарь
**Описание**: Генерирует .ics файл для Google Calendar/Apple Calendar

### 4. Голосовой ввод
**Описание**: Распознавание голосовых сообщений для добавления событий
**Пример**: Пользователь отправляет голосовое "встреча завтра в три часа"
**Технология**: Telegram Voice → Whisper API или Vosk

### 6. Бэкап на Google Drive
**Описание**: Автоматическое сохранение базы данных в облако
**Реализация**: Google Drive API / синхронизация

## Технические детали поиска

### Алгоритм гибридного поиска (v2)
```
1. Exact match (query ⊂ event_name)     → приоритет 100%
2. Starts with (event_name.startswith)   → приоритет 95%
3. Word prefix (word.startswith query)   → приоритет 90%
4. Prefix fuzzy (query ≈ начало слова)  → приоритет = score
   - Требует: ≥3 совпадающих символов И ratio ≥70%
```

### Prefix Fuzzy Matching
Новый тип поиска: сравнивает query с началом слова.
- "нату" vs "наталью" → сравнивается с "натал" (начало слова)
- ratio("нату", "натал") = 75% → найдено!
- "любимая" vs "любимую" → сравнивается с "любим" → ratio=73% → найдено!
